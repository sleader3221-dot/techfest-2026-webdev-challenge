# Submissions

Upload your files into a folder named after your team, e.g. `submissions/code-crafters/`:

```
code-crafters/
├── IDEATION.md          (by 11:00 AM, plus any images)
├── TEAM_INFO.txt        (by 1:30 PM)
└── code-crafters.zip    (by 1:30 PM: website + WORKFLOW.md)
```

**Got an invite?** Accept it at https://github.com/sleader3221-dot/techfest-2026-webdev-challenge/invitations, then click
**Add file → Upload files** above, drag your whole team folder in, choose **"Create a new branch … start a pull request"** → **Propose changes** → **Create pull request**.
Only touch your own team folder.

**No invite?** Fork this repository, upload in your fork, then **Contribute → Open pull request**.

Step-by-step help: [../docs/SUBMISSION_GUIDE.md](../docs/SUBMISSION_GUIDE.md)
